# 环境配置说明

## 1. 基础环境

| 组件 | 版本要求 | 验证命令 |
| --- | --- | --- |
| Git | ≥ 2.40 | `git --version` |
| Python | 3.9 ~ 3.12 | `python --version` |
| Java (Spark 需要) | JDK 8 或 11 | `java -version` |

## 2. Python 虚拟环境

```bash
cd bigdata-ai-coursework
python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1
# Windows Git Bash
source .venv/Scripts/activate
# macOS / Linux
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

> 若 PowerShell 提示脚本被禁止执行，先运行：
> `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

## 3. Jupyter 内核

```bash
pip install ipykernel
python -m ipykernel install --user --name bdai --display-name "BigData & AI"
```

## 4. 国内网络加速（可选）

pip 换源，避免安装依赖超时：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

常用镜像源：

- 清华：`https://pypi.tuna.tsinghua.edu.cn/simple`
- 阿里：`https://mirrors.aliyun.com/pypi/simple`
- 中科大：`https://pypi.mirrors.ustc.edu.cn/simple`

## 5. PySpark 常见问题

**Windows 报 `Python worker failed to connect back`**

设置环境变量指向本机 Python：

```bash
export PYSPARK_PYTHON=python
export PYSPARK_DRIVER_PYTHON=python
```

**缺少 winutils.exe（Hadoop 相关报错）**

下载与 Spark 内置 Hadoop 版本匹配的 `winutils.exe`，放到 `C:\hadoop\bin\`，并添加环境变量 `HADOOP_HOME=C:\hadoop`。

## 6. 大文件处理

仓库已通过 `.gitignore` 排除原始数据。如确实需要版本化管理大文件：

```bash
git lfs install
git lfs track "*.pkl"
git add .gitattributes
```
